    Website Coffe Shop

    Proyek mandiri, Oktober 2026

    Latar Belakang

    Proyek ini dibuat untuk mempelajari cara membangun website CoffeShop sederhana menggunakan HTML, CSS, dan JavaScript. Website ini berisi informasi kedai, daftar menu, harga minuman, dan informasi pemesanan.

    Fitur

    1. Menampilkan daftar menu kopi dan non coffe
    2. Menampilkan nama, deskripsi, dan harga menu
    3. Menampilkan foto produk minuman
    4. Navigasi ke bagian menu, tentang kami, dan kontak
